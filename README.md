## Дипломный проект. Задание 2: API тестирование

### Автотесты для проверки программы, которая помогает заказать бургер в Stellar Burgers

### Реализованные сценарии
Созданы API-тесты, покрывающие сценарии:
    
    Создание пользователя:
-создать уникального пользователя;
-создать пользователя, который уже зарегистрирован;
-создать пользователя и не заполнить одно из обязательных полей.

    Логин пользователя:
-логин под существующим пользователем,
-логин с неверным логином и паролем.
    Изменение данных пользователя:
-с авторизацией,
-без авторизации

    Создание заказа:
-с авторизацией,
-без авторизации,
-с ингредиентами,
-без ингредиентов,
-с неверным хешем ингредиентов.

    Получение заказов конкретного пользователя:
-авторизованный пользователь,
-неавторизованный пользователь.

### Структура проекта

- `allure-results` - пакет, содержащий отчет о тестировании
- `tests` - пакет, содержащий тесты, разделенные по разделам
- `conftest.py` - файл, содержащий фикстуру для создания пользователя
- `data.py` - файл с данными
- `urls` - файл с базовым урлом и эндпоинтами
